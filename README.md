# Sardine

Car park layout generator for Rhino 8 / Grasshopper (WSP UK).

- `docs/PRD.md` — the authoritative v1.0.0 build contract.
- `v1/` — clean v1.0.0 source drop (`.cs` files only) with directory map and
  build plan. See `v1/README.md` and `v1/BUILD_PLAN.md`.
- `legacy/` — proof-of-concept Grasshopper C# scripts (behavioural reference).
- Root `Sardine.Core/`, `Site.cs`, `*.csproj`, `*.sln` — earlier, non-building
  migration attempt kept for reference only.
